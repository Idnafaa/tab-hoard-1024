How many browser tabs do I have open? 1024. A small Python program that
keeps a ledger of the open tabs, grouped by what they are for (read-later
articles, docs, Stack Overflow and GitHub, YouTube watch-later, work
dashboards, shopping compares, half-written replies), adds the groups up
at run time, and writes the total — one number, digits only — to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (or `/output` when that
is unset). Locally, run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`
and read `out/entry.txt`.
